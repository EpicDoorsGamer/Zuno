# Zuno

Zuno is a minimal Discord bot built with Node.js and discord.js. It provides these slash commands:

```text
/whois <roblox username>
/clan assign <roblox username> <clan>
/ticket setup <panel_channel> <category> [support_role] [log_channel] [title] [description]
/ticket edit [panel_channel] [category] [support_role] [log_channel] [title] [description] [button_label] [clear_support_role] [clear_log_channel] [send_new_panel]
/ticket resend [panel_channel]
/ticket refresh
/ticket config
/ticket disable
/status set <text> [type] [presence]
/status clear
/slots [bet] or !slots [bet]
/bj [bet] or !bj [bet]
/daily or !daily
/work or !work
/balance [user] or !bal [@user]
/leaderboard or !lb
/inventory [user] or !iv [@user]
/lootbox <type> or !lootbox <type>
/ping or !ping
/chess start [opponent] [color]
/chess move <from> <to> [promotion]
/chess board [orientation]
/chess resign
```

`/whois` searches Roblox for a real account, then posts a public channel embed with the user's Roblox identity, avatar headshot, account dates, profile description, social counts, Roblox badge count, optional Roblox group membership details, and any locally assigned clan.

`/clan assign` lets authorized Discord members assign the only supported clan, `WLAN`, to a Roblox account. Assignments are stored locally by Roblox user ID.

`/ticket setup` sends a ticket panel with an Open Ticket button. Head Administrators can later edit the panel, move where it is posted, resend it, refresh the saved panel message, and change ticket destinations. Users can open one private ticket channel at a time. Staff can claim tickets so other staff can see who is handling them, and ticket owners, the configured support role, or Head Administrator and above can close tickets.

`/status` changes Zuno's Discord presence. It is restricted to bot owners `1109158652927033465` and `1211338035136954391`.

The fun economy commands support both slash commands and `!` aliases. Coins, cooldowns, inventories, blackjack stats, slots stats, and lootbox stats are saved in `data/economy.json`.

`/chess` starts a playable turn-based chess game with a generated PNG board. It uses `chess.js` for real legal move validation, then adds interactive buttons for moving, refreshing, flipping the board, and resigning. It supports server use, bot DMs, private channels, and user-installed external-app use.

## Requirements

- Node.js 20 or newer
- A Discord application and bot token

Required npm packages:

- `discord.js`
- `dotenv`
- `chess.js`
- `pngjs`

## Install

```bash
npm install
```

## Configure

Copy `.env.example` into `.env`, then fill in your values:

```env
DISCORD_TOKEN=your_discord_bot_token_here
DISCORD_APPLICATION_ID=your_discord_application_client_id_here
DISCORD_GUILD_ID=
ROBLOX_GROUP_ID=
CLAN_MANAGER_ROLE_ID=1492957184261230642
HEAD_ADMIN_ROLE_ID=1492957184261230642
CACHE_TTL_SECONDS=300
```

`DISCORD_GUILD_ID` is optional. If set, `npm run deploy` registers slash commands only in that server and updates quickly. If empty, commands are registered globally and can take a while to appear.

`ROBLOX_GROUP_ID` is optional. When set, Zuno checks whether the searched Roblox user belongs to that group and shows a CLAN section with status, rank name, and rank number. If the user is not in the configured group, Zuno shows `Status: Not a Member`.

To find a Roblox group ID, open the Roblox group/community page and copy the numeric ID from the URL.

`CLAN_MANAGER_ROLE_ID` controls who can use `/clan assign`. Members with that exact role, or any role above it in the Discord server role hierarchy, can assign `WLAN` to Roblox accounts. The default is:

```env
CLAN_MANAGER_ROLE_ID=1492957184261230642
```

Clan assignments are saved in `data/clans.json`. Do not edit this file while the bot is running.

`HEAD_ADMIN_ROLE_ID` controls who can configure tickets with `/ticket setup`, `/ticket edit`, `/ticket resend`, `/ticket refresh`, `/ticket config`, and `/ticket disable`. Members with that exact role, or any role above it in the Discord server role hierarchy, can configure the ticket system. The default is:

```env
HEAD_ADMIN_ROLE_ID=1492957184261230642
```

Ticket settings and open-ticket tracking are saved in `data/tickets.json`. Zuno also keeps `data/tickets.backup.json` when a real ticket config exists, so it can recover if the main ticket store is temporarily unreadable. Do not edit these files while the bot is running.

## Discord Bot Setup

1. Go to the Discord Developer Portal.
2. Create an application named `Zuno`.
3. Open the Bot tab, create/reset the bot token, and put it in `.env` as `DISCORD_TOKEN`.
4. Open General Information and copy the Application ID into `.env` as `DISCORD_APPLICATION_ID`.
5. In the Bot tab, enable the privileged `Message Content Intent` if you want `!slots`, `!bj`, `!daily`, and the other prefix commands to work.
6. Invite the bot with scopes `bot` and `applications.commands`.
7. Give it at least `Manage Channels`, `Send Messages`, `Embed Links`, and `Attach Files`.

Invite URL template:

```text
https://discord.com/oauth2/authorize?client_id=YOUR_APPLICATION_ID&permissions=51216&scope=bot+applications.commands
```

## Deploy Slash Commands

```bash
npm run deploy
```

Run this again after adding or changing commands, otherwise Discord may still only know about older slash commands.

For `/chess` to appear in DMs or as an external/user-installed slash command, deploy commands globally. Leave `DISCORD_GUILD_ID` empty in `.env`, then run `npm run deploy`. Guild-only deployments cannot appear in DMs.

## Fun Economy Commands

The economy is server-scoped. Each server has its own balances, inventories, and leaderboard.

```text
/daily
!daily
```

Claim daily coins every 24 hours.

```text
/work
!work
```

Work for coins every 30 minutes.

```text
/balance user:@member
!bal @member
```

Shows your balance, or another user's balance.

```text
/leaderboard
!lb
```

Shows the top 10 richest users in the server.

```text
/inventory user:@member
!iv @member
```

Shows your inventory, or another user's inventory.

```text
/slots bet:100
!slots 100
```

Spin slots with a coin bet.

```text
/bj bet:100
!bj 100
```

Starts a button-based blackjack game.

```text
/lootbox type:Common Box
!lootbox common box
```

Opens a lootbox. Available types are `Common Box`, `Uncommon Box`, `Rare Box`, `Epic Box`, and `Legendary Box`.

```text
/ping
!ping
```

Shows bot latency.

## Chess Commands

Chess games are saved in `data/chess-games.json`, so active games survive bot restarts. Zuno keeps one active chess game per channel or DM.

```text
/chess start opponent:@member color:White
```

Starts a two-player chess game. Leave `opponent` empty to start a solo board where you control both sides.

```text
/chess move from:e2 to:e4
```

Plays a legal move and posts the updated board. You can also press **Make Move** on the chess embed to open a small move form instead of typing the slash command again. Use `promotion` when a pawn promotes.

```text
/chess board orientation:Black
```

Shows the current board. Orientation is optional and defaults to your side when you are a player.

```text
/chess resign
```

Ends the active game. Only a player in the game can resign.

## Ticket Setup

Use this in Discord as a Head Administrator or higher:

```text
/ticket setup panel_channel:#tickets category:Tickets support_role:@Support log_channel:#ticket-logs
```

`panel_channel` is where Zuno posts the public Open Ticket button.

`category` is where private ticket channels are created.

`support_role` is optional. If set, that role can see and answer every ticket.

`log_channel` is optional. If set, Zuno logs ticket closes there.

Close logs are sent as a Zuno embed with ticket owner, panel name, closer, claimant, timing, message count, transcript users, and an attached `.txt` transcript file.

Use `/ticket config` to view the current setup and `/ticket disable` to turn the ticket system off without deleting existing channels.

To modify the existing panel and ticket destinations:

```text
/ticket edit title:Need Support? description:Open a ticket below. button_label:Create Ticket
```

To move the panel to another channel and post a new active panel there:

```text
/ticket edit panel_channel:#support send_new_panel:True
```

To resend the current panel without changing the rest of the setup:

```text
/ticket resend panel_channel:#support
```

To update the currently saved panel message after changing text:

```text
/ticket refresh
```

Blank `/ticket edit` options keep their old values. Use `clear_support_role:True` or `clear_log_channel:True` to remove those optional settings.

## Roblox API Endpoints Used

Zuno uses public Roblox endpoints only and never fabricates unavailable values:

- `POST https://users.roblox.com/v1/usernames/users` to resolve a username to a Roblox user ID.
- `GET https://users.roblox.com/v1/users/{userId}` to fetch profile details such as display name, username, description, creation date, and banned status.
- `GET https://thumbnails.roblox.com/v1/users/avatar-headshot` to fetch the avatar/headshot image.
- `GET https://friends.roblox.com/v1/users/{userId}/friends/count` for friend count.
- `GET https://friends.roblox.com/v1/users/{userId}/followers/count` for follower count.
- `GET https://friends.roblox.com/v1/users/{userId}/followings/count` for following count.
- `GET https://accountinformation.roblox.com/v1/users/{userId}/roblox-badges` for Roblox badge count.
- `GET https://groups.roblox.com/v2/users/{userId}/groups/roles` to check the configured Roblox group and show rank information.
- `GET https://users.roblox.com/v1/users/search` for best-effort username autocomplete. If Roblox rate limits or rejects search, autocomplete quietly returns no suggestions.

## Notes

- Command errors and clan assignment confirmations are private/ephemeral.
- Successful `/whois` lookups are posted as a public Discord channel embed.
- Ticket configuration is private/ephemeral and restricted to Head Administrator and above.
- Ticket panels are public, ticket channels are private, and users can only have one open ticket at a time.
- Ticket channels include a Claim Ticket button. Once staff claims a ticket, the ticket embed shows who claimed it and the claim button becomes disabled.
- `/status` is owner-only and saves the selected presence in `data/bot-status.json` so it can be restored after restart.
- Prefix commands use `!` and require Discord's Message Content intent to be enabled for the bot.
- Economy data is saved in `data/economy.json`.
- Chess games are saved in `data/chess-games.json`.
- Roblox lookups are cached for a short time using `CACHE_TTL_SECONDS` to reduce unnecessary API traffic.
- If Roblox omits or refuses a piece of optional data, Zuno leaves that field out instead of guessing.
